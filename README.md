## 1. 播放器增强

- **长按临时加速**：按住加速键立刻提速，松开自动还原。倍率 `0.1×` – `16×`，步进 `0.1×`，默认 `3×`。
  - 按下后 **240ms** 才进入加速态；指针位移超过 **12px** 视为拖拽并取消加速；松开后 **300ms** 内抑制点击，避免误触播放器暂停。
- **倍速 HUD**：右上角浮层实时显示当前倍速，切档不掉线。
- **快捷控制条**：可停靠的控制条，内置快退 / 快进预设（后退 `600s` `300s` `60s` `10s`，前进 `10s` `60s` `300s` `600s`）、播放暂停、画中画、循环菜单。
- **快捷条停靠**：桌面端与移动端都停靠在播放器正下方，随页面滚动一起走，不浮在画面之上；进入全屏时自动回落为浮层。
- **全屏拖拽**：全屏浮层状态下按住左侧把手可拖到屏幕任意位置，位置按站点记忆，双击把手复位。
- **自动最高清晰度**：WiFi / 宽带下自动切到该视频的最高档（如 `1080p`）。
  - 判定依据 `navigator.connection`：`saveData` 为真、`type === 'cellular'`、或 `effectiveType` 为 `2g` / `slow-2g` 时不升档并回落默认档；读不到网络信息时按可用处理。
  - 最多重试 **12 次**、间隔 **300ms**，同时监听 `loadedmetadata` / `loadeddata` / `canplay` / `canplaythrough` 四个事件直到生效。
  - 播放速率大于 `1×` 期间不切档，避免加速播放时触发重新缓冲。
- **画面锐化（关 / 轻 / 中 / 强）**：
  - `轻` = `contrast(1.06) saturate(1.07) brightness(1.01)`，`中` = `contrast(1.12) saturate(1.14) brightness(1.02)`，两者是纯 CSS filter，几乎不占资源。
  - `强` = SVG `feConvolveMatrix` 真锐化（强度 `0.35`），适合低码率 1080p，部分显卡会掉帧。
  - **掉帧保护**：播放中 FPS 低于 **40** 且连续 **2 秒**成立，自动降为「中」并写日志；暂停时监测从逐帧唤醒降为 **500ms** 轮询。
  - 只作用于画面，不影响字幕与控制条。
- **关键帧预览**：进度条轨道上标出 whos.tv 抽帧刻度，指针落在刻度 **4px** 内才弹出缩略图与时间，点击刻度直接跳到该帧的原始时间点；站内查不到番号时自动走搜索结果兜底。
  - 抓取上限 **40 页**、每页 **4 条轨道**、目标 **40 个刻度**；本地缓存 **120 条**，命中缓存不再发请求。
- **A-B 区段循环**：预设 `5s` / `10s` / `60s`，也可输入任意秒数。
- **原生画中画**：支持即启用，浏览器不支持时给出降级提示而不是静默失败。
- **剧场模式**：按视频原始比例算出目标宽高，把播放器放大到内容列宽度并收起右侧「相关影片」等侧栏，下方原本与播放器等宽的模块同步跟随新宽度，页面照常上下滚动；再按一次或 `Esc` 精确还原。进度条上的关键帧刻度会随新宽度重新对齐，预览图也放大一档。
- **自动点播**：停在「点击播放」封面的页面会尝试自动点一次播放入口，省一次点击；已在播放页时不动作。
- **快捷键全可改**：触发键、加速倍率、快进秒数都能在面板里改，输入框内自动失效。

## 2. 字幕系统

- **本地加载**：文件选择器接受 `.srt` / `.vtt` / `.ass` / `.ssa`，按 UTF-8 读取。
- **在线下载**：支持 **ZIP 包内字幕**（`store` 与 `deflate-raw` 两种压缩方式，走浏览器原生 `DecompressionStream`），并自动探测 **UTF-8 / UTF-16LE / UTF-16BE / GB18030** 编码，不乱码。
- **在线检索（5 个源）**：迅雷字幕 API、字幕猫（SubtitleCat）、SubHD、AVSub、JavSub。命中后弹出选择器挑版本，每个源按钮有「搜索中 / 有结果 / 无结果 / 出错」四态。
- **选择器双操作**：列表里每条字幕右侧有「应用」和「下载」两个按钮 —— 「应用」直接加载显示，「下载」把该条字幕存到本地，不动当前正在显示的字幕。点整行等同「应用」。
  - 下载按源文件的原始字节保存，不重新编码；如果拿到的是压缩包，会自动解出里面的字幕并按 `.srt` / `.ass` / `.vtt` 保存，解不出来才按 `.zip` 原样存。
  - 扩展名优先按内容判定（`[Script Info]` → ass/ssa，`WEBVTT` → vtt，含 `-->` → srt），再退回文件名与 URL。
  - 文件名取源站给的字幕名，非法字符替换为 `_`，不带后缀时自动补上。
  - 只提供详情页的源（SubHD、JavSub）那一行只有「打开」按钮，不会假装能下载。
- **列表可缩放**：右下角有斜纹抓手，拖动即可改宽高 —— 字幕名被截断时往右拉，就能看到完整文件名；双击抓手回到默认尺寸（宽 `346px`）。
  - 范围：宽 `320` – `760`（同时不超过视口 92%），高 `180` – 视口高度。
  - 尺寸按浏览器记忆，下次打开沿用上次的大小；改动后自动收回视口内，不会跑到屏幕外。
  - 手机上只允许改高度（宽度本来就是满屏减 12px）。
- **反爬识别**：命中 Cloudflare 挑战页时直接判为失败，不会把验证页当字幕解析。
- **时间轴偏移**：`-60s` – `+60s`，步进 `0.5s`，按站点保存，可一键重置。
- **外观**：字号 `12px` – `64px`（默认 `24px`），垂直高度 `0%` – `80%`（默认 `10%`），拖动即预览。
- **换集恢复**：切换集数后自动带出上次使用的字幕与偏移（字幕正文按番号快照保存）。
- **解析细节**：自动剥离 BOM、统一 `\r\n`、去掉 `WEBVTT` 头；ASS/SSA 的 `{\...}` 样式块与 `\N` 换行会被正确转换；时间轴用二分查找定位当前句，长片不卡。
- **渲染去重**：同一句字幕重复刷新时不再重写 DOM，位置与字号只在真正变化时才落样式，长片挂机不抖。

## 3. 音量与输出设备

- **增益放大**：基于 WebAudio，`0%` – `600%` 可调，步进 `5%`，预设 100 / 150 / 200 / 300 / 450 / 600%。
- **设备路由**：通过 `setSinkId` 把声音指定到任意输出设备（耳机、采集卡、虚拟声卡），需要 Chrome 110+ 一类支持该 API 的浏览器。
- **授权设备**：设备列表默认只给通用名（「扬声器」），点「授权设备」并允许一次麦克风权限后，才能拿到「耳机（Realtek）」这种可区分的真实名称。
- **测试音**：一键播放短促测试音，用来确认增益与路由是否真的生效，不用去翻视频。
- **按站点记忆**：增益、是否启用路由、目标设备分别存 MissAV、Jable 两套，切站互不影响。
- **跨域兜底**：检测到 CORS 限制时自动重载媒体并恢复播放进度（等待上限 `4s`），同时在面板给出明确原因，而不是静默无声。

## 4. 页面净化

- **广告清理**：移除广告 iframe、隐藏广告节点，用 `MutationObserver` 持续扫描新增节点，而不是一次性清完就完事。覆盖 Google IMA 视频广告框架、右下角直播浮窗、片商赞助文字链，以及 MissAV 导航下拉里的整列推广站。
- **浮动广告启发式**：除了固定选择器，还按 `position: fixed/sticky` + 覆盖面积 + 层级综合判定浮层广告，站点换皮肤也能命中。
- **弹窗拦截**：重写 `window.open`，跨站弹出直接吞掉，站内正常跳转放行。
- **iframe 递归**：对所有子框架同步打补丁，不留死角。
- **假 App 提示清理**：移除「打开 App 观看」这类诱导层。
- **切屏检测屏蔽**：伪造 `document.hidden` / `visibilityState` 与 `hasFocus`，拦截 `visibilitychange` / `pagehide` / `freeze` / `blur` 一类事件，并周期性复查防止被站点重新挂钩。
- **白名单保护**：播放器、站点核心节点以及脚本自身的面板 / 大屏永不误删。
- **大屏互斥**：进入三个数据大屏时，站点原生节点会被隐藏、页面内媒体会被静音，避免后台视频继续出声。

## 5. 内容过滤与屏蔽

- **关键词黑名单**：标题命中即过滤，逗号或换行分隔多条。
- **番号前缀黑名单**：如 `FC2` / `SIRO` / `LUXU`，整条厂牌线一键屏蔽。
- **女优黑名单**：填中文名即可，**简体 / 繁体 / 日文异体写法都能识别**（内置约 300 组异体字映射，如 澤/泽、繪/绘、瀬/濑），命中任一形态即过滤。
- **最短时长过滤**：`0` – `3600` 秒，步进 `60` 秒，界面按分钟显示。
- **已看管理**：点击或播放即写入本站已看库，可一键隐藏或清空（只清当前站点）。
- **弱化模式**：半透明 + 灰度替代彻底隐藏，鼠标悬停可临时恢复。
- **内嵌过滤条**：自动挂到站点标题栏，显示「本页条目 / 已过滤 / 剩余可见」三项统计，并随 DOM 变化重算；找不到合适标题栏时自动退化到浮动按钮。
- **手动重算**：面板「过滤」页的「立即重新过滤」可强制重扫当前页，并在日志里输出统计。

## 6. 情报增强

- **三栏情报面板**：官方剧照、社区短评、精选影单三个 Tab，展开即用。
- **剧照画廊**：网格 + 灯箱，左右翻页、`Esc` 关闭。
- **剧照候选链**：同一部片的多套剧照按「第一套先用、其余排队」的方式接入，某套图加载失败会自动把破图替换成下一套，而不是留一排空框；JavBus 直连被拦时自动改走 CORS 代理重试。
- **短评聚合**：JavDB 网页版详情页、JavLibrary 影评、站内评论区三源去重合并，超过 120 条时如实标注「已显示 120 / 共 N 条」，可继续「加载更多」。
- **番号解析三级回退**：JavDB 接口 → JavDB 网页搜索 → 搜索引擎索引（`site:javdb.com/v/`）。接口需要登录或跨域受限时，剧照 / 短评 / 评分 / 影单仍然照常工作。
- **评分徽章**：JavDB 评分直接插到标题前。
- **番号直达**：标题旁与大屏观影记录的番号旁各挂两个图标 —— JavBus 直连详情页，JavDB 先给搜索页、后台解析出 `/v/<id>` 真详情页后**原地替换链接**；解析结果走本地缓存，并限制并发为 **2**，不乱发请求。
- **社媒直达**：在女优名旁挂 X / Instagram 徽标，点开即搜。
- **Jable 专属**：补全女优、片商、发行信息卡片，缺失项显示为「补全中」而不是空白。
- **请求策略**：情报抓取总预算 `6s`，单次直连超时 `4.5s`；直连失败按状态码判断是否值得走代理，代理为 `allorigins` + `codetabs` 双通道并发，先到先用。
- **缓存策略**：剧照 / 短评 / 评分 / 影单四项全空时不写缓存，下次进页面自动重试；旧版本留下的空缓存会被当场丢弃；正常缓存 TTL 24 小时。

## 7. 观影行为数据大屏

面板「数据」→「打开观影行为数据大屏」，在新标签页打开 `#av-analytics`。

- **三档时间范围**：全部历史 / 近 30 天 / 近 7 天，切档即时重算所有卡片。
- **四项 KPI**：累计部数、真实有效时长、平均单片投入、深度完播率（≥75%）。
- **用户画像**：按时段、节奏、忠诚度生成专属称号与描述，范围切换后画像文案同步变化。
- **365 天热力图**：日粒度活跃强度，未来日期留空占位。
- **时间矩阵**：星期 × 小时 24×7 热力矩阵，外加 24 小时分布。
- **排行榜**：女优 TOP10、题材 TOP15、片商 TOP8，按频次 / 按时长一键切换。
- **时长分布**：<5 分 / 5–15 分 / 15–30 分 / >30 分四档。
- **继续观看**：按上次播放位置排序的续播卡片，点一下直达。
- **记录管理**：关键词搜索、单条删除、JSON 导出与导入、一键清空（带二次确认）。
- **记录开关**：数据栏里的「自动记录已看视频」「行为统计」两个开关决定是否采集，关掉之后大屏不再增长。
- **采样方式**：播放器每 5 秒采样一次，暂停、切页、关页都会强制落盘，异常退出最多丢 5 秒。

## 8. 影片收藏大屏

面板「数据」→「打开影片收藏大屏」，在新标签页打开；也可直接访问收藏页带 `?favscreen=1#fav-screen`，页面标题为「影片收藏大屏 — 增强助手」。

- **两站点独立**：数据分别存 `favScreen::v2::missav` / `favScreen::v2::jable`，互不混合。
- **三条抓取通路**：
  - MissAV 走 `/saved?page=N` HTTP 直连，被拦截时改用页内隐藏框架读取；
  - Jable 优先 HTTP 直连，含异步分页 URL 构造；
  - Jable 直连失败时退回隐藏 iframe，用真实点击翻页并拦截框架内的分页请求。
  - 全程按域名串行限速，403/429/5xx、超时、空响应这类可重试错误会自动重试；识别到反爬拦截页时直接判失败并提示，不会把拦截页当数据。
- **容量上限**：单站点最多 **8000** 条；忽略名单最多 **500** 条（超出按时间淘汰最旧）。
- **深度补全**：只读站内详情页补齐女优 / 题材 / 发行商，并发 **3**，每轮条数可调（默认 **60**），结果缓存 **7 天**；同一番号 30 分钟内失败过的不再重试。
- **六张可点 KPI**：收藏总数、女优覆盖、题材覆盖、番号识别率、平均片长、待补全。点任意一张直接在下方海报墙筛出对应条目，再点一次取消；点「收藏总数」等于清除全部筛选。
- **收藏趋势**：最近 12 个月的新增节奏，窄屏同样保留 12 个月（隔月显示标签，不再被裁成 6 个月）。

## 9. 女优收藏

面板「女优收藏」按钮进入独立大屏（`#av-actress`）。**两个站点各自独立存储**：Jable 的收藏只存在 `actressFav@jable`，MissAV 的只存在 `actressFav@missav`，在哪个站点打开就只显示该站点的收藏。

- **一行一个女优**：长名自动换行，不再被省略号截断。
- **观看统计**：用本机观影记录反查，「已看 N 部 · 累计时长 · 最近观看」，不需要联网。
- **女优档案（JavBus + 维基百科兜底）**：出生日期与年龄、身高、罩杯、三围、爱好、影片总数，另附 JavDB 的别名与收录部数；缺项自动查维基百科，面板底部写明来源与更新时间，随时可「刷新档案」。
- **真实头像**：JavBus 头像优先（请求自动带 `Referer`，否则 403），其次 JavDB，再次维基百科配图，转 Data URL 缓存 **30 天**；都没有就退回姓名首字。
- **五星评分**：点星打分，再点同一颗清零，参与「我的评分」排序。
- **标签**：单条 ≤16 字，回车即加，最多存 24 条（界面按 6 条一组展示）；顶部汇总成筛选条，点一下只看这一类。
- **备注**：单条 ≤240 字。
- **四种排序 / 三种视图**：最近添加 / 名字 / 观看部数 / 我的评分；列表 / 网格 / 大图墙。
- **名字直达本站作品**：Jable 走 `/models/`，MissAV 走 `/actresses/`，取不到时退回站内搜索。
- **站外直达**：JavDB、JavBus、维基百科、X / Instagram。
- **详情面板**：档案、观看统计四格、标签增删、备注、直达链接、最近观看时间线（最多 12 条）、一键移出。
- **批量操作**：行首勾选后批量打标签或批量移除。
- **导出 / 导入**：JSON 全量导出（收藏 + 评分 + 标签 + 备注 + 档案），导入按同名合并，不覆盖不删除。
- **自动同步**：在站点的收藏 / 女优页打开时，会自动把页面里出现的女优收进列表，不用一个个手动加。
- **数据来源**：JavBus 提供生日 / 年龄 / 身高 / 罩杯 / 三围 / 爱好 / 影片数，抓取必须带 `Accept-Language`，否则会被重定向到年龄验证页；维基百科（中文优先、日文兜底）补生日、身高、三围、罩杯与照片，只有条目名与本名字符重合 ≥ 60% 才采用；JavDB 只提供别名、作品数与头像；JavLibrary 有 403 反爬，未接入。
- **容量上限**：档案 **400** 条、头像 **120** 张、评分 / 标签 / 备注元数据 **600** 位，超出按最早写入淘汰。

## 10. 断点续播

- **自动记忆**：播放中每 5 秒落盘一次，按番号记录播放位置，关掉页面也不丢。
- **门槛**：不到 **30 秒**的片段不记；已看完（≥95%）的不打扰。
- **恢复提示**：进入视频弹 Toast 询问是否跳转，附「撤销」回到开头。
- **智能避让**：Toast 会算控制条与已有浮层的位置，避开它们，不遮画面。
- **尊重手动操作**：自己拖过进度条后，脚本不再强行覆盖。
- **双来源兜底**：优先用断点记录；没有记录时用观影记录里**看到过的最远位置**恢复。
- **实时落盘**：关页 / 切后台立即刷盘；时长还没探到的流也能先记位置。
- **与大屏联动**：数据页提供「继续观看」卡片，按位置排序。
- **可自查**：控制台执行 `__avResumeNotes` 能看到每条是「正常恢复 / 记录兜底 / 已看完 / 太早」中的哪一种。

## 11. 效率工具

- **站内自动登录**：凭据加密存放，未登录时自动提交，失败时给出具体原因而不是无声卡住；失败后 **120 秒**内不重复尝试，避免刷登录接口。
- **收藏批量备份**：字段可选（名称 / 缩略图 / 番号 / 女优 / 类型 / 发行商），条数 `1` – `2000`（默认 `50`）。
- **本地打包 ZIP**：内置 CRC32 与手写 ZIP 写入器，产出 CSV + `img/` 缩略图，不依赖任何外部服务；补全详情时并发 `3`。
- **字段补全**：缺失信息自动回查 JavDB 后合并进备份。
- **数值可直接输入**：每个滑杆右侧的数值都是输入框，回车确认、`Esc` 取消、`↑` / `↓` 按步进增减；超范围自动夹到上下限。
- **缓存清理（设置页）**：一键清掉本站脚本产生的缓存——剧照 / 短评 / 评分 / 影单、进度条关键帧、女优资料、JavDB 详情解析、社交图标——并显示条数与占用体积；三个大屏的数据、已看库、断点续播、女优收藏与全部设置都不动。

## 12. 面板、移动端与性能

- **六个页签**：播放 / 字幕 / 音频 / 过滤 / 数据 / 设置。播放页聚合加速与画质，过滤页给出三项统计与「立即重新过滤」，数据页聚合三个大屏入口与备份、清库，设置页聚合外观、平台、账号、缓存。
- **首次打开自动选页**：当前页有视频就落在「播放」，否则落在「过滤」；2.6 秒内视频出现会自动切过去，你手动点过页签后不再抢。
- **实时日志**：面板底部滚动输出每一步状态，卡在哪一步一目了然；点底栏可展开完整日志，最多保留 **240** 行。
- **面板外观**：宽度 `320` – `520`，三档快捷 `340` / `372` / `424`，按站点记忆；另有「紧凑界面」与「完整标题」两个开关（后者取消标题截断，列表与海报墙显示完整片名）。
- **透明度与模糊**：常态不透明度默认 `0.92`、背景模糊 `16px`，鼠标悬停切到 `0.96`，都可单独调。
- **缓存清理（设置 Tab）**：见上一节，显示条数与占用体积。
- **模块开关（设置 Tab）**：一键开启 / 关闭「官方剧照与社区短评」与「快捷条」。关掉情报后不再抓取剧照与短评，面板区块立即移除；关掉快捷条后播放器上的操作条立即消失且不会被重建；重开立即恢复，开关状态按站点记忆。
- **收放动画**：展开 / 收起走同一套 0.3 秒节奏，宽度与高度一起过渡；系统开启「减少动态效果」时直接切换。
- **手机端只有一个入口**：收起后是右下角一枚 52 × 52 圆角按钮（只留 logo），点它从底部升起整块面板；面板固定贴在视口底部，不随手拖动。
- **手机端细节**：左右各留 8px 不贴边，顶部 40 × 4 抓手可收起；开关恢复 18px 细长条（可点范围约 44px）；数字框 68px 宽、字号 16px（iOS 聚焦不放大）；面板展开时快捷条自动让位。
- **移动端专属**：播放时保持屏幕常亮；锁屏 / 耳机线控可暂停、继续；双击视频左半边快退、右半边快进；竖屏下控件自动避让刘海与手势条。
- **Dock 停靠与全屏浮层**：桌面 / 移动都先尝试停靠在播放器下方；全屏或找不到可用宿主时自动切成浮层，并记住每个站点的浮层位置。
- **SPA 感知**：路由切换后自动重建整套 UI，不用手动刷新；旧 UI 会做孤儿节点清扫，不会越叠越多。
- **平台三档**：自动识别 / 强制移动端 / 强制桌面端，切换后自动刷新；也可用 `?avplat=mobile` / `?avplat=desktop` 临时指定，不写入存储。
- **性能**：
  - 番号解析结果按 URL 缓存，5000 次解析从 ~80ms 降到 ~2ms；
  - 元数据抽取的 DOM 查询从 8 次降到 5 次，全文扫描结果按数据版本号缓存；
  - 字幕、进度条、锐化滤镜等高频 DOM 写入全部改为「先比对再写」，重复渲染的变更次数降为 0；
  - 锐化监测在暂停时从逐帧唤醒改为 500ms 轮询，播放时自动切回逐帧；
  - 统计序列化结果按「数组引用 + 版本号」复用，未变更时不再重复 `JSON.stringify`；
  - 收藏大屏的渲染缓存按数据版本复用，1200 条测试库重复刷新从 ~47ms 降到 ~29ms；
  - 情报面板改为「分区签名」：剧照 / 短评 / 统计三区各自只在内容变化时重建，同一部片四个来源并发回填也不重复重排（单页新增节点 ~3300 → ~1100）；
  - 拖动中的面板、快捷条、剧场窗口不再逐帧读取元素尺寸（改为按下时记一次），滚动帧的强制同步布局减少 4~6 次；
  - 图标 SVG 与设置面板 HTML 改为模板缓存 + 克隆，重复渲染不再重复解析 `innerHTML`；
  - 广告节点清扫队列改为 Set 去重，同一节点不再重复入队；关键帧定时器的「写→读→再读」合并为一次读取；
  - 收藏大屏日志改为追加式渲染，长日志不再每次全量重画；仪表盘回放进度先比文本指纹再解析，未变更时跳过 300 KB JSON 解析与一次无用存储读取。

## 13. 存储与数据模型

所有键都由脚本自己管理，前缀固定，方便排查与清理。

| 键 / 前缀 | 内容 | 上限与策略 |
|:---|:---|:---|
| `avSub:*` | 全部设置项（倍速、偏移、黑名单、面板尺寸等） | 逐项独立键，改一项只写一项 |
| `avSub:offset@missav` / `@jable` | 字幕时间轴偏移 | 按站点 |
| `avSub:audio*@missav` / `@jable` | 增益、路由开关、设备 ID 与名称 | 按站点 |
| `avSub:watchedList@<site>` | 已看库 | 按站点，可单独清空 |
| `avSub:analyticsRecords_v1@<site>` | 观影行为记录 | 按站点，每 5 秒采样 |
| `avSub:resumePlayback_v1@<site>` | 断点续播位置 | 按番号，30 秒起记 |
| `avSub:whosFrames_v1` | 关键帧缩略图索引 | 120 条，版本号不符即丢弃 |
| `avSub:info:v4:*` | 剧照 / 短评 / 评分 / 影单缓存 | TTL 24 小时，四项全空不写 |
| `avSub:actress2:*` | 女优档案 | 400 条 |
| `avSub:actressFav@<site>` | 女优收藏 | 按站点 |
| `avCred:*` | 登录凭据 | 优先油猴存储，降级 XOR + Base64 |
| `favScreen::v2::<site>` | 收藏条目 + 忽略名单 + 同步记录 | 8000 条 / 忽略 500 |
| `favScreen::v2::<site>::settings` | 排序、视图、每轮补全条数、模块显隐 | 与大屏数据分离 |
| `favScreen::v2::<site>::enriched` | 详情缓存 | 7 天，清空影片不连带删 |

- **合并落盘**：改动先进队列，**200ms** 后一次性写入；切后台、`pagehide`、关页前强制 `flush`，不会丢刚做的操作。
- **双写降级**：油猴环境写 `GM_setValue`，同时可写 `localStorage`；存储写满时自动触发缓存清扫再重试一次。
- **自查接口**：控制台 `__avPersist.state` 可看队列与写入计数，`__avPersist.flush()` 可手动落盘。

## 数据与隐私

- 所有配置与统计只存在本机，走油猴 `GM_setValue` 或 `localStorage`，主脚本键名前缀 `avSub:`，收藏大屏前缀 `favScreen::v2::`，不上传任何服务器。
- 登录密码优先写入油猴存储；降级方案为 **XOR + Base64** 混淆，*仅用于规避明文，不等同于加密*，是否保存请自行判断。
- 跨站请求只用于字幕检索、评分 / 剧照 / 短评补全、收藏备份、关键帧抓取（whos.tv）、JavDB 详情解析、JavBus 女优档案与维基百科兜底，统一走 `GM_xmlhttpRequest`。
- 关键帧、JavDB 详情页与女优档案都会本地缓存（分别上限 120 条 / 240 条 / 30 天），命中缓存时不再发起请求；女优头像最多留 120 张，档案上限 400 条。
- 收藏大屏的详情缓存独立存 `favScreen::v2::<site>::enriched`，清空影片不会连带删掉详情。
- 写盘采用合并落盘：改动先攒一小会儿再一次性写入，关闭页面或切走标签页前强制写完，不会丢失刚刚的操作。
