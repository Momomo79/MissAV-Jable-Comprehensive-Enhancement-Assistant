🎬 MissAV & Jable 综合增强助手
专为 MissAV、Jable.tv 等相关视频网站打造的终极浏览器增强脚本。本脚本集成了高级外挂字幕系统、高度自定义的播放快捷键、沉浸式页面净化以及高颜值的毛玻璃 UI 控制面板，致力于为您带来最丝滑、最舒适的观影体验！

✨ 核心功能亮点
🍎 1. 苹果风磨砂玻璃控制面板
极简美学：精心设计的毛玻璃（Frosted Glass）半透明 UI 界面，不遮挡观影视线，完美融入原站风格。

动态光晕：内置炫酷的光标跟随光晕效果，让每一次交互都充满科技感。

便捷唤出：面板支持便捷折叠与展开，随时随地调整设置。

🔤 2. 旗舰级字幕系统
原站没有中文字幕？本脚本为你提供完整的字幕解决方案：

本地字幕加载：支持一键选择或拖拽加载本地的 .srt 格式字幕文件。

在线智能匹配：集成迅雷 API 与网页字幕搜索引擎，一键查找并挂载匹配的在线中文字幕。

时间轴校准：遇到字幕与画面不同步？支持字幕时间轴偏移调整（提前/延后），精准对齐每一句台词。

⏩ 3. 极客级播放控制
打破原站播放器的基础限制，为您提供更符合直觉的操控方式：

自定义快捷键：支持在控制面板中完全自定义您习惯的键盘快捷键。

长按临时加速：支持设定特定按键（如长按右方向键），实现临时倍速播放，松开即恢复原速，跳过无聊片段的绝佳利器！

精准快进/倒退：自定义单次快进/倒退的秒数，观影节奏由你掌控。

🧹 4. 沉浸式页面与交互优化
强力去广告：自动清理页面中多余的横幅广告和弹窗，还您一个干净清爽的选片环境。

标签超链接化：将视频底部的普通分类标签转换为可直接点击的超链接，同类影片一键直达。

女优资料悬浮预览：在影片列表或详情页，鼠标悬停于女优名称即可弹出悬浮资料卡，无需频繁跳转页面即可了解详情。

📖 操作说明与使用指南
安装脚本：在浏览器安装好 Tampermonkey 插件后，点击本页面的“安装”按钮即可。

打开控制面板：进入 MissAV 或 Jable.tv 的视频播放页面后，页面侧边（或指定位置）会出现增强助手的悬浮按钮，点击即可展开高级设置面板。

加载字幕：

在面板中找到“字幕设置”模块。

若有下载好的文件，点击“选择本地文件”上传 .srt 字幕。

若无文件，点击“在线搜索字幕”，脚本会自动抓取影片番号进行匹配。

调整快捷键：在面板的“快捷键设置”中，点击对应的功能输入框，然后按下您想要绑定的键盘按键即可完成修改。

🛠️ 常见问题 (FAQ)
Q: 字幕显示乱码怎么办？
A: 请确保您的本地 .srt 字幕文件编码为 UTF-8。如果是其他编码格式，建议使用记事本打开后另存为 UTF-8 格式再加载。

Q: 快捷键和系统或其他插件冲突了？
A: 可以在控制面板中重新绑定快捷键，建议使用不常用的组合键或单键。

Q: 页面样式显示错位或部分功能失效？
A: 目标网站可能会不定期更新前端代码。如果发现失效，请在 GreasyFork 的“反馈”区留言，我会尽快跟进修复。
