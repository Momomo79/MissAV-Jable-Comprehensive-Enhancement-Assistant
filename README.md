🚀 MissAV & Jable 综合增强助手 (Enhanced Assistant)一个专为 PC 端 打造的 MissAV 与 Jable 网页视频增强油猴脚本（Tampermonkey Script）。旨在提供更极致的观影体验，集成了便捷的控制面板、全功能字幕加载、自由倍速与快进、广告清理以及一键快捷交互。

✨ 核心功能 (Features)

🖥️ PC端专用优化：智能识别桌面设备与精细指针，过滤移动端干扰，专注大屏体验。

🎛️ 可拖拽控制面板：磨砂玻璃 UI 设计，支持鼠标任意拖拽、一键折叠/展开，并自动记忆面板位置。

🧹 智能广告清理：内置动态监听（MutationObserver），自动清理页面烦人的悬浮广告、弹窗及多余 iframe。

💬 强大的字幕系统：支持本地 .srt 字幕文件拖拽或点击加载。内置网页快速搜索（跳转 SubtitleCat）与 API 联网搜索匹配字幕功能。支持字幕时间轴偏移微调（$\pm 30$ 秒）。

⚡ 倍速与快进控制：支持自定义加速倍数（最高 16x）、自定义快进/倒退秒数，支持快捷键临时加速。

⌨️ 便捷快捷键支持：空格键 (Space)：控制视频播放/暂停。自定义快捷键：可自由设置加速、快进、倒退键（防输入框焦点冲突）。

🎬 悬浮快捷控制栏：视频下方集成一键快退/快进（10s、1m、5m、10m）、播放/暂停按钮。支持双击视频左右两侧快速快进/倒退 10 秒。

📜 实时运行日志：控制面板内置带时间戳的实时状态日志栏，运行情况一目了然。

📦 安装与使用 (Installation)首先确保你的浏览器已安装油猴插件（如 Tampermonkey）。点击访问你的脚本源码，或直接复制脚本内容。在油猴面板中新建脚本，将代码粘贴进去并保存即可。打开支持的网站（如 MissAV、Jable 视频播放页），即可在页面中看到控制面
板与悬浮快捷栏。

度）。悬浮快捷栏透明度与模糊度：修改 .custom-quick-controls 中的 background 与 backdrop-filter: blur(8px)。
