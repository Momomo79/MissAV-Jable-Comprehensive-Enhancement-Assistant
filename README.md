# MissAV & Jable 综合增强助手

支持 MissAV 与 Jable · 纯本地运行，数据不上传。

一个脚本接管：广告清理、字幕、播放控制、影片情报、内容过滤、观影统计。

## 功能

**广告清理**
- 自动隐藏广告图层、移除广告 iframe
- 拦截弹窗与跳转劫持
- 增量监听页面变化，保护播放器与验证码

**字幕**
- 加载本地 SRT / VTT / ASS / SSA
- 网页搜索、API 搜索并下载字幕
- 偏移调节，按站点分别记忆，默认 0，可重置本站偏移
- 字号、显示高度可调，字幕悬浮条显示文件名与条数

**播放增强**
- 长按画面临时倍速，松开还原
- 原生画中画、区间循环、快进 / 倒退（秒数可调，支持长按连发）

**影片情报**
- 评分徽章、官方剧照画廊与灯箱、社区短评、精选影单
- 女优列表与社交直达
- jable播放页作品资料卡片：女优、发行时间、片商、导演、系列
- jable偏爱片商 TOP 8 自动统计并补全

**内容过滤与屏蔽**
- 过滤总开关、隐藏已看、弱化显示（半透明加灰度）
- 标题关键词黑名单、番号前缀黑名单、最短时长过滤
- 自动记录已看视频，可一键清空已看库
- 列表页内嵌快捷过滤条，实时显示过滤计数

**观影数据大屏**（个人中心）
- 指标：累计观影部数、真实有效时长、平均单片投入、深度完播率
- 用户画像：观影原型、叙事、签名标签、活跃时段、节奏偏好、专注度
- 近 365 天热力图、时长分布、女优 TOP 10、题材 TOP 15、片商 TOP 8
- 记录明细支持搜索、分页、删除、跳转播放；标题与片商自动补全
- 时间范围切换、导出 JSON、清空数据

## 安装

1. 安装 Tampermonkey 扩展
2. 新建脚本，粘贴脚本全文并保存
3. 打开站点自动生效，播放页左上角为控制面板

## 数据与隐私

- 全部数据存于浏览器本地 localStorage，不上传、不云同步
- 字幕偏移、设置、已看库、观影记录均只在本机
- 清空数据与清空已看库均为本地操作，无法恢复

## 常见问题

**字幕加载失败**：确认已授予脚本 `@connect` 权限，或改用「加载本地」。

**偏移不生效**：偏移按站点分别记忆，默认 0，可点「重置本站偏移」。

**面板位置乱了**：面板可拖拽，位置自动记忆，可点「重置面板位置」。

**脚本图标没更新**：Tampermonkey 有图标缓存，重装脚本或刷新面板即可。
