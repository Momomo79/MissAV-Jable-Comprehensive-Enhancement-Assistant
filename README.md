## 1. 播放器增强

- **长按临时加速**：按住加速键立刻提速，松开自动还原；倍率可设 `0.1×` – `16×`，默认 `3×`。
- **倍速 HUD**：右上角浮层实时显示当前倍速，切档不掉线。
- **快捷控制条**：可停靠的控制条，内置快退 / 快进预设 `10s` `60s` `300s` `600s`、播放暂停、画中画、循环菜单。
- **快捷条停靠**：桌面端与移动端都停靠在播放器正下方，随页面滚动一起走，不浮在画面之上；进入全屏时自动回落为浮层。
- **全屏拖拽**：全屏浮层状态下按住左侧把手可拖到屏幕任意位置，位置按站点记忆，双击把手复位。
- **自动最高清晰度**：WiFi / 宽带下自动切到该视频的最高档（如 `1080p`），蜂窝、省流量模式、2G 保持自适应不升档；最多重试 20 次并监听媒体事件直到生效。
- **画面锐化（关 / 轻 / 中 / 强）**：`轻`、`中` 用颜色矩阵轻微提亮与加强对比，几乎不占资源；`强` 用 SVG 卷积做真锐化，适合低码率 1080p，部分显卡会掉帧，**掉帧时自动降为「中」并写日志**。只作用于画面，不影响字幕与控制条。
- **关键帧预览**：进度条轨道上标出 whos.tv 抽帧刻度，**指针落在刻度上才弹出缩略图与时间**，点击刻度直接跳到该帧的原始时间点；站内查不到番号时自动走搜索结果兜底。
- **A-B 区段循环**：预设 `5s` / `10s` / `60s`，也可输入任意秒数。
- **原生画中画**：支持即启用，浏览器不支持时给出降级提示而不是静默失败。
- **剧场模式**：把播放器放大到内容列宽度并收起右侧「相关影片」等侧栏，下方原本与播放器等宽的模块同步跟随新宽度，页面照常上下滚动；再按一次或 `Esc` 精确还原。进度条上的关键帧刻度会随新宽度重新对齐，预览图也放大一档。
- **快捷键全可改**：触发键、加速倍率、快进秒数都能在面板里改，输入框内自动失效。

## 2. 字幕系统

- **格式**：SRT / VTT / ASS / SSA，自动剥离 BOM 与 `WEBVTT` 头。
- **编码探测**：UTF-8 / UTF-16LE / UTF-16BE / GB18030 自动识别，不乱码。
- **ZIP 直读**：直接把压缩包拖进来，自动解出里面的字幕文件。
- **在线检索**：内置 SubtitleCat 网页检索与迅雷字幕 API 两条通路，命中后弹出选择器挑版本。
- **时间轴偏移**：`-60s` – `+60s` 微调，**按站点保存**，可一键重置。
- **外观**：字号 `12px` – `64px`，垂直高度 `0%` – `80%`，拖动即预览。
- **换集恢复**：切换集数后自动带出上次使用的字幕与偏移。
- **渲染去重**：同一句字幕重复刷新时不再重写 DOM，位置与字号只在真正变化时才落样式，长片挂机不抖。

## 3. 音量与输出设备

- **增益放大**：基于 WebAudio，`0%` – `600%` 可调，预设 100 / 150 / 200 / 300 / 450 / 600%。
- **设备路由**：通过 `setSinkId` 把声音指定到任意输出设备（耳机、采集卡、虚拟声卡）。
- **按站点记忆**：增益与设备分别存 MissAV、Jable 两套。
- **跨域兜底**：检测到 CORS 限制时自动重载媒体并恢复播放进度，同时在面板给出明确原因。

## 4. 页面净化

- **广告清理**：移除广告 iframe、隐藏广告节点，用 `MutationObserver` 持续扫描新增节点，而不是一次性清完就完事。覆盖 Google IMA 视频广告框架、右下角直播浮窗、片商赞助文字链，以及 MissAV 导航下拉里的整列推广站。
- **弹窗拦截**：重写 `window.open`，跨站弹出直接吞掉，站内正常跳转放行。
- **iframe 递归**：对所有子框架同步打补丁，不留死角。
- **切屏检测屏蔽**：伪造 `visibilityState` 与 `hasFocus`，拦截 `visibilitychange` / `pagehide` / `freeze` / `blur` 一类事件，并周期性复查防止被重新挂钩。
- **白名单保护**：播放器、站点核心节点以及脚本自身的面板 / 大屏永不误删。

## 5. 内容过滤与屏蔽

- **关键词黑名单**：标题命中即过滤，逗号或换行分隔多条。
- **番号前缀黑名单**：如 `FC2` / `SIRO` / `LUXU`，整条厂牌线一键屏蔽。
- **最短时长过滤**：`0` – `3600` 秒滑杆，界面按分钟显示。
- **已看管理**：点击或播放即写入本站已看库，可一键隐藏或清空（只清当前站点）。
- **弱化模式**：半透明 + 灰度替代彻底隐藏，鼠标悬停可临时恢复。
- **内嵌过滤条**：自动挂到站点标题栏，显示命中统计并随 DOM 变化重算。

## 6. 情报增强

- **三栏情报面板**：官方剧照、社区短评、精选影单三个 Tab，展开即用。
- **剧照画廊**：网格 + 灯箱，左右翻页、`Esc` 关闭。
- **社区短评**：抓取评论区并去重聚合，超过 120 条时如实标注「已显示 120 / 共 N 条」。
- **评分徽章**：JavDB 评分直接插到标题前。
- **番号直达**：标题旁与大屏观影记录的番号旁各挂两个图标 —— JavBus 直连详情页，JavDB 先给搜索页、后台解析出 `/v/<id>` 真详情页后**原地替换链接**；解析结果走本地缓存，不乱发请求。
- **社媒直达**：在女优名旁挂 X / Instagram 徽标，点开即搜。
- **Jable 专属**：补全女优、片商、发行信息卡片。
- **缓存策略**：剧照 / 短评 / 评分 / 影单四项全空时不写缓存，下次进页面自动重试；旧版本留下的空缓存会被当场丢弃。

## 7. 观影行为数据大屏

面板「数据」→「打开观影行为数据大屏」，在新标签页打开 `#av-analytics`。

- **四项 KPI**：累计部数、真实有效时长、平均单片投入、深度完播率（≥75%）。
- **用户画像**：按时段、节奏、忠诚度生成专属称号与描述。
- **365 天热力图**：日粒度活跃强度，未来日期留空占位。
- **时间矩阵**：星期 × 小时 24×7 热力矩阵，外加 24 小时分布。
- **排行榜**：女优 TOP10、题材 TOP15、片商 TOP8，按频次 / 按时长一键切换。
- **时长分布**：<5 分 / 5–15 分 / 15–30 分 / >30 分四档。
- **数据管理**：JSON 导出与导入、单条删除、一键清空。
- **记录开关**：数据栏里的「自动记录已看视频」「行为统计」两个开关决定是否采集，关掉之后大屏不再增长。
- **采样方式**：播放器每 5 秒采样一次，暂停、切页、关页都会强制落盘，异常退出最多丢 5 秒。

## 8. 影片收藏大屏

面板「数据」→「打开影片收藏大屏」，在新标签页打开；也可直接访问收藏页带 `?favscreen=1#fav-screen`，页面标题为「影片收藏大屏 — 增强助手」。

- **两站点独立**：MissAV 走 `/saved?page=N` 逐页直连（被拦截时改用页内框架读取），Jable 走收藏页翻页（直连失败时在后台隐藏 iframe 里点击翻页）；数据分别存 `favScreen::v2::missav` / `favScreen::v2::jable`，互不混合。
- **深度补全**：只读站内详情页补齐女优 / 题材 / 发行商，并发 3，每轮条数可调，结果缓存 7 天。
- **六张可点 KPI**：收藏总数、女优覆盖、题材覆盖、番号识别率、平均片长、待补全。点任意一张直接在下方海报墙筛出对应条目，再点一次取消；点「收藏总数」等于清除全部筛选。
- **收藏趋势**：最近 12 个月的新增节奏，窄屏自动收敛为 6 个月。
- **排行与构成**：女优 TOP 12、题材 TOP 12（点击任意一行即按该女优 / 题材过滤）、番号前缀分布、番号识别率与完整度环形图。
- **女优合作网络**：同一部作品同框的女优之间连线，线越粗合作越多、节点越大作品越多，最多 40 位；悬停高亮相邻连线，点击节点立刻按该女优筛选并滚动定位；手机 / 平板 / 桌面三档画布，底部给出「合作最多的一对」。
- **播放进度对接**：直接读取观影统计，海报底部 3px 进度条（看完变绿）+ 右下角 `62%` / `已看完` 角标；工具栏可按未观看 / 观看中 / 已看完筛选，排序新增「最近观看」。
- **海报墙**：搜索番号 / 标题 / 女优 / 题材（160ms 防抖）、随机一部（`R`）、海报与列表双视图、五种排序（收藏顺序 / 最新收录 / 番号 / 片长 / 最近观看）、悬停复制番号与 JavDB 搜索、懒加载骨架屏、无限滚动。
- **模块显隐**：齿轮里可单独关掉收藏趋势、数据排行、番号与构成、女优网络、海报墙，只看关心的部分。
- **维护工具**：清理未见条目（整轮抓完且覆盖 ≥50% 才提示，带二次确认）、重复番号一键去重、清空影片与清空详情分开操作。
- **导出**：收藏条目 + 详情缓存打包成 JSON 下载。
- **移动端与平板**：手机上工具栏搜索独占一行、两个下拉各占 44% 并排、海报两列、操作按钮 30px、搜索框 16px 防 iOS 放大；平板上海报与 KPI 三列、排行卡并排、趋势恢复 12 个月。

## 9. 女优收藏

面板「女优收藏」按钮进入独立大屏（`#av-actress`）。**两个站点各自独立存储**：Jable 的收藏只存在 `actressFav@jable`，MissAV 的只存在 `actressFav@missav`，在哪个站点打开就只显示该站点的收藏。

- **一行一个女优**：长名自动换行，不再被省略号截断。
- **观看统计**：用本机观影记录反查，「已看 N 部 · 累计时长 · 最近观看」，不需要联网。
- **女优档案（JavBus + 维基百科兜底）**：出生日期与年龄、身高、罩杯、三围、爱好、影片总数，另附 JavDB 的别名与收录部数；缺项自动查维基百科，面板底部写明来源与更新时间，随时可「刷新档案」。
- **真实头像**：JavBus 头像优先（请求自动带 `Referer`，否则 403），其次 JavDB，再次维基百科配图，转 Data URL 缓存 30 天；都没有就退回姓名首字。
- **五星评分**：点星打分，再点同一颗清零，参与「我的评分」排序。
- **标签与备注**：最多 6 个标签，回车即加；顶部汇总成筛选条，点一下只看这一类。
- **四种排序 / 三种视图**：最近添加 / 名字 / 观看部数 / 我的评分；列表 / 网格 / 大图墙。
- **名字直达本站作品**：Jable 走 `/models/`，MissAV 走 `/actresses/`，取不到时退回站内搜索。
- **站外直达**：JavDB、JavBus、维基百科、X / Instagram。
- **详情面板**：档案、观看统计四格、标签增删、备注、直达链接、最近观看时间线（最多 12 条）、一键移出。
- **批量操作**：行首勾选后批量打标签或批量移除。
- **导出 / 导入**：JSON 全量导出（收藏 + 评分 + 标签 + 备注 + 档案），导入按同名合并，不覆盖不删除。
- **数据来源**：JavBus 提供生日 / 年龄 / 身高 / 罩杯 / 三围 / 爱好 / 影片数，抓取必须带 `Accept-Language`，否则会被重定向到年龄验证页；维基百科（中文优先、日文兜底）补生日、身高、三围、罩杯与照片，只有条目名与本名字符重合 ≥ 60% 才采用；JavDB 只提供别名、作品数与头像；JavLibrary 有 403 反爬，未接入。

## 10. 断点续播

- **自动记忆**：播放中每 5 秒落盘一次，按番号记录播放位置，关掉页面也不丢。
- **恢复提示**：进入视频弹 Toast 询问是否跳转，附「撤销」回到开头。
- **智能避让**：Toast 避开控制条与已有浮层，不遮画面。
- **尊重手动操作**：自己拖过进度条后，脚本不再强行覆盖。
- **双来源兜底**：优先用断点记录；没有记录时用观影记录里**看到过的最远位置**恢复，已看完（≥95%）的不打扰。
- **实时落盘**：关页 / 切后台立即刷盘，不到 30 秒的片段不记；时长还没探到的流也能先记位置。
- **与大屏联动**：数据页提供「继续观看」卡片，按位置排序。
- **可自查**：控制台执行 `__avResumeNotes` 能看到每条是「正常恢复 / 记录兜底 / 已看完 / 太早」中的哪一种。

## 11. 效率工具

- **站内自动登录**：凭据加密存放，未登录时自动提交，失败时给出具体原因而不是无声卡住。
- **收藏批量备份**：字段可选（名称 / 缩略图 / 番号 / 女优 / 类型 / 发行商），条数 `1` – `2000`。
- **本地打包 ZIP**：内置 CRC32 与手写 ZIP 写入器，产出 CSV + `img/` 缩略图，不依赖任何外部服务。
- **字段补全**：缺失信息自动回查 JavDB 后合并进备份。
- **数值可直接输入**：每个滑杆右侧的数值都是输入框，回车确认、`Esc` 取消、`↑` / `↓` 步进；超范围自动夹到上下限。

## 12. 面板、移动端与性能

- **实时日志**：面板底部滚动输出每一步状态，卡在哪一步一目了然。
- **面板外观**：宽度三档 `340` / `372` / `424` 按站点记忆，另有「紧凑界面」开关；播放页正文区固定为合适高度，切 Tab 不会忽长忽短。
- **收放动画**：展开 / 收起走同一套 0.3 秒节奏，宽度与高度一起过渡；系统开启「减少动态效果」时直接切换。
- **手机端只有一个入口**：收起后是右下角一枚 52 × 52 圆角按钮（只留 logo），点它从底部升起整块面板；面板固定贴在视口底部，不随手拖动。
- **手机端细节**：左右各留 8px 不贴边，顶部 40 × 4 抓手可收起；开关恢复 18px 细长条（可点范围约 44px）；数字框 68px 宽、字号 16px（iOS 聚焦不放大）；面板展开时快捷条自动让位。
- **移动端专属**：播放时保持屏幕常亮；锁屏 / 耳机线控可暂停、继续；双击视频左半边快退、右半边快进；竖屏下控件自动避让刘海与手势条。
- **SPA 感知**：路由切换后自动重建整套 UI，不用手动刷新。
- **性能**：
  - 番号解析结果按 URL 缓存，5000 次解析从 ~80ms 降到 ~2ms；
  - 元数据抽取的 DOM 查询从 8 次降到 5 次，全文扫描结果按数据版本号缓存；
  - 字幕、进度条、锐化滤镜等高频 DOM 写入全部改为「先比对再写」，重复渲染的变更次数降为 0；
  - 锐化监测在暂停时从逐帧唤醒改为 500ms 轮询，播放时自动切回逐帧；
  - 统计序列化结果按「数组引用 + 版本号」复用，未变更时不再重复 `JSON.stringify`；
  - 收藏大屏的渲染缓存按数据版本复用，1200 条测试库重复刷新从 ~47ms 降到 ~29ms。

## 安装与使用

1. 在浏览器扩展商店安装 **Tampermonkey**（Violentmonkey 亦可）。
2. 打开[项目主页](https://github.com/Momomo79/MissAV-Jable-Comprehensive-Enhancement-Assistant)，点击脚本的 **Raw / 安装** 链接，扩展会自动弹出安装页，确认即可。
3. 打开任意支持站点，页面左上角出现「综合增强助手」面板。**按住标题可拖动**，点齿轮折叠；折叠后是一条小胶囊，点箭头还原。
4. 面板底部按钮显示当前识别结果，点击可在 **自动识别 → 强制移动端 → 强制桌面端** 三档间循环，切换后自动刷新；也可用 `?avplat=mobile` / `?avplat=desktop` 参数临时指定。
5. 改完设置点「保存设置」；要看统计点「数据」页里的两个大屏按钮，要管理女优点「女优收藏」。

## 数据与隐私

- 所有配置与统计只存在本机，走油猴 `GM_setValue` 或 `localStorage`，主脚本键名前缀 `avSub:`，收藏大屏前缀 `favScreen::v2::`，不上传任何服务器。
- 登录密码优先写入油猴存储；降级方案为 **XOR + Base64** 混淆，*仅用于规避明文，不等同于加密*，是否保存请自行判断。
- 跨站请求只用于字幕检索、评分 / 剧照 / 短评补全、收藏备份、关键帧抓取（whos.tv）、JavDB 详情解析、JavBus 女优档案与维基百科兜底，统一走 `GM_xmlhttpRequest`。
- 关键帧、JavDB 详情页与女优档案都会本地缓存（分别上限 120 条 / 240 条 / 30 天），命中缓存时不再发起请求；女优头像最多留 120 张，档案上限 400 条。
- 收藏大屏的详情缓存独立存 `favScreen::v2::<site>::enriched`，清空影片不会连带删掉详情。
- 写盘采用合并落盘：改动先攒一小会儿再一次性写入，关闭页面或切走标签页前强制写完，不会丢失刚刚的操作。
- 情报四项全空时不写入缓存，下次进页面自动重试；旧版本留下的空缓存会被当场丢弃。
- JavBus 请求固定直连（不走公共代理，避免丢失年龄 Cookie 拿到验证页），超时放宽到 8 秒；「清空已看库」只影响当前站点。
