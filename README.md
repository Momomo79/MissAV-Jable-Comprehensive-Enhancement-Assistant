# MissAV & Jable 综合增强助手

一个给 **MissAV / Jable** 用的播放增强脚本：倍速、字幕、画中画、界面净化，外加一整套从 JavBus / JAVLibrary / JavDB 抓取的**情报聚合体系**——评分、剧照、短评、影单，全部内嵌在页面里。所有设置保存在浏览器本地，不上传任何数据。

---

## 🆕 v9.0 全新更新内容

### 1️⃣ 长按画面倍速 + HUD

按住画面 **240 毫秒**，视频临时加速；松手立刻回到原速。

- 屏幕顶部浮现**倍速指示器**，显示当前倍数与「加速中」状态
- 手指或鼠标移动超过 **12 像素**自动取消，因此不会和「滑动调进度」冲突
- 点在按钮、输入框、字幕上**不会误触发**

### 2️⃣ 原生画中画

一键把视频弹出为系统画中画窗口。

- 支持 Chrome / Edge 的标准接口
- **也支持 Safari** 的 `webkitSetPresentationMode` 回退
- 快捷栏按钮或按 `P` 键触发

### 3️⃣ 权威评分徽章

从 **JAVLibrary** 与 **JavDB** 抓取**真实评分**——不是本地估算。

- 统一换算为 **10 分制**
- 显示评分来源与评价人数
- **JAVLibrary 优先**
- 位置在**影片标题行最前面**，一眼就能看到

### 4️⃣ 社区短评聚合

并发抓取 **JavBus、JAVLibrary、JavDB** 三站短评，加上页面自带评论，**合并去重**后集中展示，每条都标注来源用户与时间。

### 5️⃣ 女优社交媒体直达

自动识别页面上的女优名，在名字旁注入 **X（Twitter）** 与 **Instagram** 直达徽章，点一下就能跳转。

### 6️⃣ 剧照画廊与全屏灯箱

- 自动抓取官方剧照，网格展示
- 点击任意一张打开**全屏灯箱**，支持 `←` `→` 切换、`Esc` 关闭，也可点两侧箭头
- 自动过滤「即将上映」占位图与无效链接

## 📦 情报区块（页面内嵌，非浮层）

一个可折叠区块，**内嵌在播放器下方、影片标题上方**，跟随页面正常滚动。

### 折叠标题栏

- 左侧线性图标 + 标题「官方剧照与社区短评」
- 右侧统计，**只显示有内容的项**：`10 剧照` / `20 讨论` / `6 影单`，数量为 0 的自动隐藏
- 箭头指示展开状态，点击标题栏展开 / 收起

### 展开后：三个标签页

| 标签页 | 内容 |
| --- | --- |
| **官方剧照 (N)** | 网格布局，自适应列宽（最小 170px，宽屏一行约 5 张），16:10 圆角、图片裁切填充，悬停微微上浮。点击任意一张打开全屏灯箱 |
| **社区短评 (N)** | 卡片列表，标注来源用户与时间 |
| **精选影单 (N)** | 收录本片的 JavDB 影单：影单名、部数、`♡ 收藏数`、`👁 浏览数`（万→`w`、千→`k`）。点「**展开影片**」可直接在站内列出影单里收录的影片（封面 + 番号，点击跳 MissAV 搜索），或点「**原站 ↗**」去 JavDB 看完整影单 |

- 进入视频页后**自动加载**，无需手动点击
- 抓不到数据时**不显示该区块**，不会留一个空白框

## 🎬 播放控制

- **临时加速**：按住 `Z` 键加速，松开恢复原速，加速倍数可调（0.1× 起）
- **快进 / 后退**：`X` 快进、`C` 后退，单次跳转秒数可调
- **播放 / 暂停**：空格键，或快捷栏按钮
- **区间循环**：5 秒 / 10 秒 / 60 秒循环，适合反复看某一段
- **快捷键自定义**：加速键、快进键、倒退键都可在面板里改成你习惯的按键

## 🎞 快捷工具栏

鼠标移入播放器即浮现，离开自动隐藏，可贴边吸附。

- 后退按钮：**10 秒 / 1 分钟 / 5 分钟 / 10 分钟**
- 前进按钮：**10 秒 / 1 分钟 / 5 分钟 / 10 分钟**
- 播放 / 暂停按钮（状态实时同步）
- 画中画按钮
- 循环菜单

## 📝 字幕支持

- **本地字幕加载**：支持 `.srt` `.vtt` `.ass` `.ssa` 四种格式
- **网页搜字幕**：按番号一键跳转 SubtitleCat 检索
- **API 搜字幕**：内置迅雷字幕接口，直接拉取可用字幕列表并在页面内选择
- **字幕偏移**：手动微调时间轴，范围 -60 ~ +60 秒
  - **按站点分别记忆**：MissAV 与 Jable 各存一套值，互不干扰
  - 调好后点「保存设置」，本站所有视频都沿用，**重进页面依然保持**
  - 提供「重置本站偏移」一键归零
- **字幕字号**：实时滑块调节（12px 起）
- **字幕高度**：实时滑块调节，控制字幕距底部的位置
- 字幕渲染为独立图层，不干扰播放器原生控件

## 🎨 界面定制

- **可拖拽控制面板**：按住标题栏任意拖动，位置自动记忆
- **可折叠**：面板可最小化，不挡画面
- **透明度滑块**：常规状态与鼠标悬浮状态**分别设置**
- **磨砂（模糊）滑块**：常规状态与悬浮状态**分别设置**
- **重置面板位置**：一键回到左上角
- **实时日志**：面板底部显示脚本每一步动作（加载字幕、跳转、抓取情报等）

## 🧹 页面净化

- 自动移除广告容器、右下角固定悬浮层、第三方 iframe
- **持续监听**：页面动态插入的广告会被即时清理，不只是加载时清一次
- **自身节点保护**：脚本自己注入的 UI 绝不会被误删
- 自动点击播放入口，省去手动找播放按钮
- 拦截恶意弹窗（含 iframe 内的 `window.open`）
- 旧域名（`missav.com` / `thisav.com`）自动跳转到 `missav.live`

## 🛡 健壮性

- 任一第三方数据源失效时**自动降级**，不影响脚本其它功能
- 第三方站点被拦截时**给出明确提示**，而不是弹出空白面板
- 请求失败自动**重试一次**并尝试 CORS 代理回退
- 切换视频时**自动清理**上一部的情报、画廊与影单缓存，避免串数据
- 情报带 **24 小时缓存**，返回同一部影片时秒开
- 移动端自动省略桌面 UA 头，**减少被拦截概率**

## 🚀 使用方法

1. 安装 Tampermonkey（油猴）扩展
2. 点击本页「安装此脚本」
3. 打开视频页面，鼠标移入播放器即可看到快捷工具栏
4. 左侧面板可调整全部设置，改完记得点「保存设置」
5. 面板挡住画面时，点「重置面板位置」即可回到左上角
6. 字幕偏移调好后点「保存设置」，本站所有视频都会沿用

## ⌨️ 快捷键

| 按键 | 功能 |
| --- | --- |
| `P` | 画中画 |
| `Z` | 按住临时加速 |
| `X` | 快进 |
| `C` | 后退 |
| `空格` | 播放 / 暂停 |

> 快捷键均可在面板中自定义。双击画面为播放器原生全屏行为，脚本不做拦截。

## 📌 说明

- 评分、剧照、短评、影单均来自第三方站点抓取，**数据真实性取决于源站**，源站改版或限制访问时可能暂时取不到
- 所有设置存储于浏览器本地，不上传任何数据
- 字幕偏移按站点分别保存，两个站点互不影响
- 字幕检索与情报抓取需要 `GM_xmlhttpRequest` 权限
- 脚本**不含任何广告或统计**，所有数据只用于页面展示
- 遇到不兼容的站点可直接反馈，会尽快适配
