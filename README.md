# 🚀 MissAV & Jable 综合增强助手

![Version](https://img.shields.io/badge/version-5.0-blue.svg)
![Platform](https://img.shields.io/badge/platform-PC%20(Desktop)-orange.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

专为 **PC 端** 设计的 MissAV 与 Jable 综合视频增强油猴脚本。旨在提供极致、流畅、沉浸式的观影体验，集成了强大的字幕加载、便捷的区间循环、自定义倍速、快进控制以及广告清理等实用功能。

---

## ✨ 核心功能亮点

*   **🖱️ 现代化可拖拽 UI**
    *   面板支持**自由拖拽**与一键收起/展开。
    *   内置高级磨砂毛玻璃效果，支持自定义**常规/悬浮状态下的透明度与模糊度**。
*   **💬 强大而灵活的字幕系统**
    *   支持本地 `.srt` 字幕文件一键导入。
    *   支持**字幕时间轴偏移调整**（微调对齐）。
    *   支持 **SubtitleCat 网页一键搜索** 与 **迅雷 API 在线字幕检索**，智能匹配。
*   **⏩ 高效倍速与快进控制**
    *   支持自定义快捷键**临时加速**（按住加速，松开恢复）。
    *   支持自由调节快进/倒退步长。
    *   支持**视频画面双击**快进（左侧双击倒退 10 秒，右侧双击快进 10 秒）。
*   **🔂 区间循环播放**
    *   快捷控制栏集成竖向排版区间循环。
    *   支持快速选择 5秒、10秒、1分钟或**自定义时间循环**。
*   **🧹 智能广告清理**
    *   自动过滤页面干扰元素与全屏/悬浮广告广告，还你清爽干净的观看环境。
*   **📝 实时日志栏**
    *   内置可视化状态日志，脚本运行动态实时掌握。

---

## ⌨️ 默认快捷键指南

| 快捷键 | 功能 | 说明 |
| :---: | :--- | :--- |
| `Space` | **播放 / 暂停** | 快捷控制视频播放状态 |
| `Z` | **临时加速** | 按住时以设定倍数加速，松开恢复原速（可自定义） |
| `X` | **快进** | 按设定秒数快速前进（可自定义） |
| `C` | **倒退** | 按设定秒数快速后退（可自定义） |
| `鼠标双击` | **局部快进/倒退** | 双击视频左侧倒退 10 秒，右侧快进 10 秒 |

## 📦 安装与使用

1. 确保您的浏览器已安装油猴插件：[Tampermonkey](https://www.tampermonkey.net/)。
2. 点击安装本脚本源码（或在 Tampermonkey 中新建脚本并粘贴代码）。
3. 访问支持的网站，脚本将自动在 PC 端激活并加载控制面板。

---

## 🌐 支持的网站

*   **MissAV**: `missav.ws` / `missav.live` / `missav.ai` / `missav.fans` / `missav.media` 等
*   **Jable**: `jable.tv/videos/*`
